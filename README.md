# CSCE-2110-Project-1 - Campus Resource Reservation System
## Project Description
The program allows users to view campus resources, create and cancel reservations, manage a waiting list, restore cancelled reservations, sort resources, and generate reports. The project also uses different data structures to manage the system. A queue is used for the waiting list, a stack is used to keep track of cancelled reservations, and a linked list is used to store active reservations.
## Features
- View available campus resources
- Create reservations
- Cancel reservations
- Add students to a waiting list
- Remove students from the waiting list
- Display the waiting list
- Restore the most recently cancelled reservation
- Display cancellation history
- Sort resources
- Generate a system report
